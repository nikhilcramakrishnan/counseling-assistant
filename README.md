## Project Workflow

The project consists of three main stages, implemented across the provided Jupyter notebooks:

1.  **Dataset Preparation (`dataset_prep.ipynb`)**:
    * Loads the `nbertagnolli/counsel-chat` dataset, which contains anonymized user questions and counselor responses related to mental health.
    * Groups the data by the original user question, combining multiple counselor answers for each unique question to capture a broader range of perspectives.
    * Utilizes the OpenAI API (specifically, `gpt-3.5-turbo`) to generate the *synthetic* structured therapy plans mentioned in the warning above. This process takes the user's concern and the aggregated counselor responses as input and prompts the model to output a plan.
    * The target structure for the generated plans includes four key sections:
        * `Core Issue`: A summary of the user's main problem.
        * `Suggested Coping Strategies`: Potential methods to manage the issue, derived from counselor insights.
        * `Immediate Actions`: Concrete first steps the user could consider.
        * `Long-term Focus Areas`: Deeper areas for potential exploration or therapeutic work.

2.  **LLM Fine-Tuning (`llm_finetuning.ipynb`)**:
    * Selects a powerful base LLM (`unsloth/Meta-Llama-3.1-8B-bnb-4bit`), which is already optimized for memory efficiency using 4-bit quantization.
    * Employs the `Unsloth` library, designed to significantly accelerate the fine-tuning process and reduce memory requirements, making it feasible on consumer-grade hardware.
    * Applies Parameter-Efficient Fine-Tuning (PEFT) using the QLoRA (Quantized Low-Rank Adaptation) technique. This method involves training only a small number of adapter weights rather than the entire model, further enhancing efficiency.
    * Loads the processed dataset (from the JSONL file generated in the previous step) and formats each entry into a conversational structure (user prompt -> assistant response) using the Llama chat template.
    * Splits the formatted data into training and evaluation sets to monitor performance.
    * Configures the training parameters (learning rate, batch size, epochs, etc.) using `SFTConfig` and initiates the fine-tuning process with `SFTTrainer` from the TRL library.
    * After training, the learned LoRA adapter weights are merged back into the base model to create a standalone, fine-tuned model.
    * The final merged model is saved locally and pushed to the Hugging Face Hub for easy access and deployment under the name `nikhil-c-r/counsel_assist`.

3.  **Inference (`inference.ipynb`)**:
    * Provides a practical demonstration of how to use the fine-tuned model (`nikhil-c-r/counsel_assist`).
    * Loads the model directly from the Hugging Face Hub using the `transformers` library.
    * Presents several example user prompts (mental health concerns formatted as chat messages).
    * Shows how to feed these prompts to the pipeline and displays the model's generated output, which should be the structured therapy plan (Core Issue, Coping Strategies, etc.).

## Goal

The overarching objective of this project is to develop an AI assistant specialized in mental health guidance. By fine-tuning an LLM on counselor interactions and synthetically generated structured plans, the aim is to create a model that can:

* Understand a user's expressed mental health challenge.
* Generate a coherent, structured plan outlining the core problem, potential coping mechanisms, immediate steps, and long-term considerations.
* Provide preliminary, structured support based on the patterns and information learned during training.

**(Please refer to the warning section above regarding the limitations and risks associated with this model).**

## Key Technologies

* **Programming Language**: Python
* **Environment**: Jupyter Notebooks
* **Core ML/LLM Libraries**:
    * `transformers` (Hugging Face): For model loading, tokenization, and pipelines.
    * `datasets` (Hugging Face): For loading and manipulating the CounselChat dataset.
    * `trl` (Hugging Face): For the `SFTTrainer` used in supervised fine-tuning.
    * `peft` (Hugging Face): For implementing Parameter-Efficient Fine-Tuning techniques like LoRA/QLoRA.
    * `unsloth`: For accelerated and memory-efficient fine-tuning.
    * `torch`: The underlying deep learning framework.
* **APIs**: OpenAI API (for synthetic data generation).
* **Experiment Tracking**: Weights & Biases (`wandb`).
* **Data Handling**: `json`, `os`, `dotenv`.

## How to Use the Fine-Tuned Model

The `inference.ipynb` notebook serves as a guide. The key steps are:
1.  Install necessary libraries (`transformers`, `torch`, etc.).
2.  Load the fine-tuned model using `pipeline("text-generation", model="nikhil-c-r/counsel_assist")`.
3.  Format your input prompt as a list of chat message (e.g., `[{"role": "user", "content": "Your mental health concern here..."}]`).
4.  Pass the message list to the pipeline object to get the generated structured plan.

**(Remember the warnings: This model uses synthetic data and should not be used for real-world applications or considered professional advice.)**
